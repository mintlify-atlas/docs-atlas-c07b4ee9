## What is DRAIT Mini-MES?

DRAIT Mini-MES is a modular manufacturing execution system (MES) designed specifically for metalworking and welding shops. It provides complete production tracking, work order management, and traceability in a ready-to-deploy Docker-based solution for on-premise installation.

## Technology Stack

DRAIT Mini-MES is built with modern, proven technologies:

- **Frontend**: React 18 + TypeScript + Vite + TanStack Query + Recharts
- **Backend**: NestJS + TypeScript + Prisma ORM + JWT authentication
- **Database**: PostgreSQL 16
- **Infrastructure**: Docker + Docker Compose + Nginx reverse proxy

## Use Cases

DRAIT Mini-MES is ideal for:

- **Small to medium metalworking shops** that need to move from spreadsheets to a real system
- **Welding shops** tracking multiple concurrent jobs with material consumption
- **Custom fabrication businesses** managing quotations and converting them to work orders
- **Workshops** requiring audit trails and compliance reporting
