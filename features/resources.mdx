## Overview

The Resources module manages all production assets in your facility, categorized as either human operators (`HUMANO`) or machines/equipment (`MAQUINA`). Each resource tracks its operational status and can be assigned to work orders.

## Resource Types

### HUMANO (Human)

Represents operators, technicians, and production personnel.

**Use Cases:**
- Machine operators
- Welders, assemblers
- Quality control inspectors
- Maintenance technicians

### MAQUINA (Machine)

Represents equipment, machines, and tools.

**Use Cases:**
- CNC machines
- Welding equipment
- Assembly stations
- Inspection tools

## Resource Status

<Steps>
  <Step title="DISPONIBLE (Available)">
    Resource is ready and available for assignment
  </Step>
  <Step title="OCUPADO (Busy)">
    Currently assigned to active work order
  </Step>
  <Step title="MANTENIMIENTO (Maintenance)">
    Under maintenance, preventive or corrective
  </Step>
  <Step title="FUERA_DE_LINEA (Offline)">
    Out of service, broken, or decommissioned
  </Step>
</Steps>

## API Endpoints

### List Resources

```http
GET /resources
```

**Query Parameters:**

<ParamField query="type" type="string" optional>
  Filter by resource type: `HUMANO`, `MAQUINA`
</ParamField>

<ParamField query="status" type="string" optional>
  Filter by status: `DISPONIBLE`, `OCUPADO`, `MANTENIMIENTO`, `FUERA_DE_LINEA`
</ParamField>

<ParamField query="search" type="string" optional>
  Search by name or sector
</ParamField>

**Response:**

```json
[
  {
    "id": "res123",
    "type": "MAQUINA",
    "name": "Torno CNC-01",
    "sector": "Mecanizado",
    "status": "DISPONIBLE",
    "notes": "Última mantención: 15/02/2026",
    "isActive": true,
    "createdAt": "2025-01-10T10:00:00Z"
  },
  {
    "id": "res456",
    "type": "HUMANO",
    "name": "García, Juan - Soldador",
    "sector": "Soldadura",
    "status": "OCUPADO",
    "notes": "Certificación AWS D1.1",
    "isActive": true,
    "createdAt": "2025-01-15T09:00:00Z"
  }
]
```

### Get Resource by ID

```http
GET /resources/:id
```

### Create Resource

```http
POST /resources
```

**Required Roles:** `DUENO`, `SUPERVISOR`, `ADMIN`

**Request Body:**

<ParamField body="type" type="enum" required>
  Resource type: `HUMANO` or `MAQUINA`
</ParamField>

<ParamField body="name" type="string" required>
  Resource name or identifier (max 120 chars)
</ParamField>

<ParamField body="sector" type="string" optional>
  Department, area, or sector (max 120 chars)
</ParamField>

<ParamField body="status" type="enum" optional>
  Initial status: `DISPONIBLE` (default), `OCUPADO`, `MANTENIMIENTO`, `FUERA_DE_LINEA`
</ParamField>

<ParamField body="notes" type="string" optional>
  Notes, certifications, or maintenance info (max 500 chars)
</ParamField>

**Example - Machine:**

```json
{
  "type": "MAQUINA",
  "name": "Fresadora CNC-02",
  "sector": "Mecanizado",
  "status": "DISPONIBLE",
  "notes": "Haas VF-2, capacidad 762x406x508mm"
}
```

**Example - Operator:**

```json
{
  "type": "HUMANO",
  "name": "Pérez, María - Operadora CNC",
  "sector": "Mecanizado",
  "status": "DISPONIBLE",
  "notes": "Experiencia 5 años, certificada Fanuc"
}
```

### Update Resource

```http
PATCH /resources/:id
```

**Required Roles:** `DUENO`, `SUPERVISOR`, `ADMIN`

**Request Body:** Same fields as Create (all optional)

Common updates:
- Change `status` when resource availability changes
- Update `notes` after maintenance
- Modify `sector` when reorganizing

**Example - Set to Maintenance:**

```json
{
  "status": "MANTENIMIENTO",
  "notes": "Mantenimiento preventivo programado - Lubricación y calibración"
}
```

### Delete Resource

```http
DELETE /resources/:id
```

**Required Roles:** `DUENO`, `SUPERVISOR`, `ADMIN`

Note: Resources with active assignments or operation logs cannot be deleted.

## Resource Assignments

When assigning a resource to a work order:

```http
POST /work-orders/:workOrderId/assignments
```

**Request Body:**

```json
{
  "resourceId": "res123",
  "userId": "user456"  // Optional: link to User if HUMANO
}
```

<ParamField path="id" type="string">

</ParamField>

</ParamField>

  Resource ID
</ParamField>

<ParamField path="userId" type="string | null">
  User ID if resource is HUMANO type
</ParamField>

<ParamField path="assignedAt" type="datetime">
  Assignment timestamp
</ParamField>

<ParamField path="unassignedAt" type="datetime | null">

## Best Practices

<AccordionGroup>
  <Accordion title="Naming Conventions">
    **Machines:**
    - Include type and number: `Torno CNC-01`, `Soldadora MIG-03`
    - Use asset codes if available: `ASSET-1234`
    
    **Humans:**
    - Format: `LastName, FirstName - Role`
    - Example: `García, Juan - Soldador`
    - Include specialty: `Pérez, Ana - Operadora CNC`
  </Accordion>
  
  <Accordion title="Status Management">
    - Set `OCUPADO` automatically when assigned to active work order
    - Return to `DISPONIBLE` when work order completes
    - Use `MANTENIMIENTO` for scheduled preventive maintenance
    - Mark `FUERA_DE_LINEA` for broken or decommissioned equipment
  </Accordion>
  
  <Accordion title="Sector Organization">
    Organize resources by production area:
    - `Mecanizado` - CNC machines, lathes
    - `Soldadura` - Welding stations and welders
    - `Ensamble` - Assembly areas
    - `Calidad` - Quality control equipment
    - `Mantenimiento` - Maintenance tools
  </Accordion>
  
  <Accordion title="Notes Field">
    **For Machines:**
    - Technical specifications
    - Last maintenance date
    - Capacity and limitations
    - Operating manual reference
    
    **For Operators:**
    - Certifications (e.g., "AWS D1.1")
    - Years of experience
    - Specialized training
    - Shift assignments
  </Accordion>
</AccordionGroup>

## Usage Examples

### Creating a Machine Resource

```typescript
import { api } from '@/shared/api/http';

const createMachine = async () => {
  const response = await api.post('/resources', {
    type: 'MAQUINA',
    name: 'Prensa Hidráulica-05',
    sector: 'Conformado',
    status: 'DISPONIBLE',
    notes: 'Capacidad 200 ton, última mantención: 01/03/2026'
  });
  return response.data;
};
```

### Creating an Operator Resource

```typescript
const createOperator = async () => {
  const response = await api.post('/resources', {
    type: 'HUMANO',
    name: 'Rodríguez, Carlos - Tornero',
    sector: 'Mecanizado',
    status: 'DISPONIBLE',
    notes: 'Experiencia 10 años, turno mañana'
  });
  return response.data;
};
```

### Updating Resource Status

```typescript
const setMaintenance = async (resourceId: string) => {
  const response = await api.patch(`/resources/${resourceId}`, {
    status: 'MANTENIMIENTO',
    notes: 'Mantenimiento preventivo programado - Retorna 15/03'
  });
  return response.data;
};
```

### Filtering Resources

```typescript
const getAvailableMachines = async () => {
  const response = await api.get('/resources', {
    params: {
      type: 'MAQUINA',
      status: 'DISPONIBLE'
    }
  });
  return response.data;
};
```
