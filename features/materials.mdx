## Overview

The Materials module provides comprehensive inventory management for production inputs. Track stock levels, unit costs, movements (entries/adjustments), and consumption tied to work orders with cost snapshots for accurate financial tracking.

### Get Material by ID

```http
GET /materials/:id
```

Returns full material details including movement history and consumption records.

### Create Material

```http
POST /materials
```

**Required Roles:** `DUENO`, `SUPERVISOR`, `ADMIN`

**Request Body:**

<ParamField body="name" type="string" required>
  Material name (max 120 chars)
</ParamField>

<ParamField body="category" type="string" optional>
  Material category or family (max 80 chars)
</ParamField>

<ParamField body="unit" type="string" required>
  Unit of measure (max 30 chars) - e.g., `kg`, `m`, `m2`, `l`, `u`
</ParamField>

<ParamField body="unitCost" type="decimal" required>
  Cost per unit (min: 0)
</ParamField>

<ParamField body="stock" type="decimal" required>
  Initial stock quantity (min: 0)
</ParamField>

**Example:**

```json
{
  "name": "Perfil IPN 200",
  "category": "Perfiles Estructurales",
  "unit": "m",
  "unitCost": 15000.00,
  "stock": 50.000
}
```

### Update Material

```http
PATCH /materials/:id
```

**Required Roles:** `DUENO`, `SUPERVISOR`, `ADMIN`

**Request Body:** Same fields as Create (all optional)

**Note:** Use the Adjust Stock endpoint to modify stock levels rather than direct PATCH.

### Adjust Stock

```http
POST /materials/:id/adjust-stock
```

**Required Roles:** `DUENO`, `SUPERVISOR`, `ADMIN`

**Request Body:**

<ParamField body="quantity" type="decimal" required>
  Quantity to add (positive) or remove (negative)
</ParamField>

<ParamField body="unitCost" type="decimal" required>
  Cost per unit for this transaction (min: 0)
</ParamField>

<ParamField body="note" type="string" optional>
  Reason or note for adjustment
</ParamField>

**Example - Stock Entry:**

```json
{
  "quantity": 25.5,
  "unitCost": 8200.00,
  "note": "Compra proveedor ABC - Factura #12345"
}
```

Creates a `ENTRADA` movement and increases stock by 25.5 units.

**Example - Stock Adjustment:**

```json
{
  "quantity": -3.2,
  "unitCost": 8000.00,
  "note": "Ajuste por inventario físico - merma detectada"
}
```

Creates an `AJUSTE` movement and decreases stock by 3.2 units.

### Delete Material

```http
DELETE /materials/:id
```

**Required Roles:** `DUENO`, `SUPERVISOR`, `ADMIN`

Note: Materials with consumption history cannot be deleted.

## Material Consumption (Work Orders)

Material consumption is recorded from the Work Orders module:

```http
POST /work-orders/:workOrderId/consumptions
```

**Request Body:**

<ParamField body="materialId" type="string" required>
  Material ID to consume
</ParamField>

<ParamField body="quantity" type="decimal" required>
  Quantity to consume (min: 0.001)
</ParamField>

<ParamField body="note" type="string" optional>
  Consumption note
</ParamField>

**Example:**

```json
{
  "materialId": "mat123",
  "quantity": 12.5,
  "note": "Consumo para fabricación de estructura"
}
```

**System Actions:**

1. Validates material exists and has sufficient stock
2. Deducts `quantity` from material stock
3. Snapshots current `unitCost` to `unitCostSnapshot` (preserves historical cost)
4. Creates `MaterialConsumption` record linked to work order
5. Creates `MaterialMovement` of type `CONSUMO`
6. Creates `MATERIAL_CONSUMIDO` event in operation log

**Cost Snapshot:**

The `unitCostSnapshot` field captures the material's unit cost at the moment of consumption. This ensures accurate cost tracking even if the material's `unitCost` changes later due to new purchases.

## Best Practices

<AccordionGroup>
  <Accordion title="Naming Conventions">
    - Use descriptive names: `Chapa de acero galvanizado 1.5mm`
    - Include key specifications in the name
    - Keep category consistent: `Metales`, `Soldadura`, `Pinturas`
  </Accordion>
  
  <Accordion title="Unit of Measure">
    Common units:
    - `kg` - Kilograms (electrodes, wire)
    - `m` - Meters (profiles, tubes)
    - `m2` - Square meters (sheets, plates)
    - `l` - Liters (liquids, paints)
    - `u` - Units (bolts, fittings)
    
    Keep units consistent across similar materials.
  </Accordion>
  
  <Accordion title="Stock Adjustments">
    - Always use the Adjust Stock endpoint, not direct PATCH
    - Positive quantities for purchases/entries
    - Negative quantities for corrections/shrinkage
    - Include detailed notes:
      - Purchase: "Compra proveedor X - Factura #123"
      - Adjustment: "Inventario físico - merma detectada"
      - Return: "Devolución OT-2026-045"
  </Accordion>
  
  <Accordion title="Cost Management">
    - Update `unitCost` when purchasing at new prices
    - Use weighted average cost for accurate valuation
    - Cost snapshots on consumption preserve historical accuracy
    - Review cost deviations in productivity reports
  </Accordion>
  
  <Accordion title="Consumption Tracking">
    - Record consumptions in real-time during production
    - Add notes for unusual consumption patterns
    - Compare consumption vs. estimates for process improvement
    - Use consumption data to refine future quotations
  </Accordion>
</AccordionGroup>

## Usage Examples

### Creating a Material

```typescript
import { api } from '@/shared/api/http';

const createMaterial = async () => {
  const response = await api.post('/materials', {
    name: 'Tubo estructural 50x50x2mm',
    category: 'Perfiles',
    unit: 'm',
    unitCost: 3500.00,
    stock: 100.0
  });
  return response.data;
};
```

### Stock Entry (Purchase)

```typescript
const recordPurchase = async (materialId: string) => {
  const response = await api.post(`/materials/${materialId}/adjust-stock`, {
    quantity: 50.0,
    unitCost: 3600.00,  // New purchase price
    note: 'Compra Proveedor MetalCorp - Factura #A-12345'
  });
  return response.data;
};
```

### Stock Adjustment (Inventory)

```typescript
const adjustInventory = async (materialId: string) => {
  const response = await api.post(`/materials/${materialId}/adjust-stock`, {
    quantity: -2.5,  // Negative for reduction
    unitCost: 3500.00,
    note: 'Ajuste inventario físico - merma por oxidación'
  });
  return response.data;
};
```

### Recording Consumption in Work Order

```typescript
const consumeMaterial = async (workOrderId: string, materialId: string) => {
  const response = await api.post(
    `/work-orders/${workOrderId}/consumptions`,
    {
      materialId: materialId,
      quantity: 15.5,
      note: 'Consumo para estructura principal'
    }
  );
  return response.data;
};
```
