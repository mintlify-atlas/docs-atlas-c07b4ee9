## Overview

The Reports API provides aggregated data and analytics for dashboards and business intelligence. All endpoints require authentication.

## GET /reports/dashboard

Retrieve dashboard summary with key performance indicators (KPIs).

### Authentication
**Required**: JWT Bearer token

Returns a dashboard object with various metrics.

## GET /reports/productivity

Retrieve productivity report with detailed filtering options.

### Authentication
**Required**: JWT Bearer token

### Query Parameters

<ParamField query="from" type="string">
  Start date for the report period (ISO 8601 format, e.g., "2026-03-01").
</ParamField>

<ParamField query="to" type="string">
  End date for the report period (ISO 8601 format, e.g., "2026-03-31").
</ParamField>

<ParamField query="clientId" type="string">
  Filter by specific client ID.
</ParamField>

<ParamField query="operatorId" type="string">
  Filter by specific operator/user ID.
</ParamField>

<ParamField query="status" type="string">
  Filter by work order status.
</ParamField>

### Response

Returns productivity metrics and statistics.

<ResponseField name="summary" type="object">
  Summary statistics for the period.
  
  <ResponseField name="totalWorkOrders" type="number">
    Total work orders in the period.
  </ResponseField>
  
  <ResponseField name="completedWorkOrders" type="number">
    Completed work orders.
  </ResponseField>
  
  <ResponseField name="totalEstimatedHours" type="number">
    Sum of estimated hours (in minutes).
  </ResponseField>
  
  <ResponseField name="totalActualHours" type="number">
    Sum of actual hours worked (in minutes).
  </ResponseField>
  
  <ResponseField name="averageEfficiency" type="number">
    Average efficiency percentage (actual vs estimated).
  </ResponseField>
  
  <ResponseField name="totalRevenue" type="number">
    Total estimated revenue/cost.
  </ResponseField>
</ResponseField>

<ResponseField name="byClient" type="array">
  Breakdown by client.
  
  <ResponseField name="clientId" type="string">
    Client ID.
  </ResponseField>
  
  <ResponseField name="clientName" type="string">
    Client name.
  </ResponseField>
  
  <ResponseField name="workOrders" type="number">
    Number of work orders.
  </ResponseField>
  
  <ResponseField name="revenue" type="number">
    Total revenue from this client.
  </ResponseField>
</ResponseField>

<ResponseField name="byOperator" type="array">
  Breakdown by operator/user.
  
  <ResponseField name="userId" type="string">
    User ID.
  </ResponseField>
  
  <ResponseField name="userName" type="string">
    User full name.
  </ResponseField>
  
  <ResponseField name="assignedWorkOrders" type="number">
    Work orders assigned to this operator.
  </ResponseField>
  
  <ResponseField name="completedWorkOrders" type="number">
    Work orders completed.
  </ResponseField>
  
  <ResponseField name="totalHours" type="number">
    Total hours worked (in minutes).
  </ResponseField>
</ResponseField>

<ResponseField name="workOrders" type="array">
  Detailed list of work orders in the period (optional, based on filters).
</ResponseField>

### Example Request

```bash
curl -X GET "https://api.example.com/reports/productivity?from=2026-03-01&to=2026-03-31" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

## Report Types

### Dashboard Report
- **Purpose**: Real-time overview of operations
- **Use Case**: Main dashboard display, operations monitoring
- **Update Frequency**: Real-time
- **Data Scope**: Current state of all entities

### Productivity Report
- **Purpose**: Analyze performance over time periods
- **Use Case**: Performance reviews, capacity planning, billing
- **Update Frequency**: Historical analysis
- **Data Scope**: Time-based aggregations with filtering

## Key Metrics Explained

### Efficiency
Calculated as: `(Estimated Hours / Actual Hours) × 100`
- **> 100%**: Work completed faster than estimated (efficient)
- **= 100%**: Work completed exactly as estimated
- **< 100%**: Work took longer than estimated (inefficient)

### Utilization
Calculated as: `(Busy Hours / Total Available Hours) × 100`
- Shows how much time resources are actively working
- Helps identify underutilized or overutilized resources

### Revenue
Sum of `estimatedCost` from all work orders in the period
- Based on estimated costs (actual costs can be calculated from material consumptions)

## Date Range Filtering

When using `from` and `to` parameters:
- Dates are inclusive (includes both start and end dates)
- Use ISO 8601 format: `YYYY-MM-DD` or full timestamp
- If omitted, defaults to current month or all-time (implementation-dependent)

## Performance Considerations

Productivity reports can be resource-intensive for large datasets:
- Use date ranges to limit data volume
- Filter by client or operator for focused analysis
- Consider caching results for frequently requested periods

## Error Responses

### 400 Bad Request
Returned when date parameters are invalid.

```json
{
  "statusCode": 400,
  "message": "Invalid date format. Use ISO 8601 (YYYY-MM-DD)"
}
```
